### 1. Redis 服务器磁盘性能测试
Redis 的持久化方式：

RDB：快照，周期性写入大文件，属于顺序写。

AOF：日志，可选同步策略（always/everysec/no），通常为顺序写且可能同步。

#### 测试 1：顺序写吞吐量（模拟 AOF 或 RDB）
```shell
fio --name=redis_seq_write --directory=/data --filename=redis_test --rw=write --bs=1M --iodepth=32 --direct=1 --numjobs=1 --size=50G --runtime=120s --time_based --group_reporting --output=redis_seq_write.txt
```

参数说明

参数	含义
--rw=write	顺序写
--bs=1M	块大小 1MB，模拟 RDB 大块写入
--iodepth=32	队列深度 32，提升吞吐
--direct=1	绕过页缓存，直接落盘
--numjobs=1	单线程，避免多线程竞争
--size=50G	每个 job 文件大小 50GB（足够大）
--runtime=120s	运行 120 秒，基于时间
--time_based	时间优先，忽略 --size 限制
--group_reporting	汇总显示所有 job 结果

预期输出示例
```text
WRITE: bw=256MiB/s (268MB/s), 256MiB/s-256MiB/s (268MB/s-268MB/s), io=30.0GiB (32.2GB), run=120001msec
```
bw：带宽 256 MiB/s，即 268 MB/s。

io：总写入数据量 30 GiB。

#### 测试 2：同步顺序写（模拟 AOF always 模式）
```shell
fio --name=redis_sync_write --directory=/data --filename=redis_sync --rw=write --bs=8k --iodepth=1 --direct=1 --sync=1 --numjobs=1 --size=10G --runtime=120s --time_based --group_reporting --output=redis_sync_write.txt
```

参数说明

--bs=8k：AOF 每次追加的数据块大小（可调整）。

--iodepth=1：单队列深度，配合 --sync=1 每次写入后立即刷盘。

--sync=1：每次 IO 后调用 fsync()，保证数据落盘。

预期输出示例

text
WRITE: bw=12.5MiB/s (13.1MB/s), 12.5MiB/s-12.5MiB/s (13.1MB/s-13.1MB/s), io=1.50GiB (1.61GB), run=120001msec
带宽明显下降（12.5 MiB/s），反映同步刷盘的性能瓶颈。

#### 测试 3：随机读（模拟缓存未命中时读取 RDB 或 AOF）
```shell
fio --name=redis_randread --directory=/data --filename=redis_rand --rw=randread --bs=16k --iodepth=64 --direct=1 --numjobs=4 --size=20G --runtime=120s --time_based --group_reporting --output=redis_randread.txt
```
参数说明

--rw=randread：随机读。

--bs=16k：常见数据库页大小。

--iodepth=64：高队列深度，提升并发 IOPS。

--numjobs=4：4 个并发进程模拟多线程读取。

预期输出示例
```text
READ: bw=204MiB/s (214MB/s), 204MiB/s-204MiB/s (214MB/s-214MB/s), io=23.9GiB (25.7GB), run=120001msec
IOPS = bw / bs = 204 MiB/s ÷ 16 KiB = 13056 IOPS。
```

同时输出 iops 和 lat（延迟）信息。

### 2. MySQL 服务器磁盘性能测试
   MySQL InnoDB 典型 IO 模式：

随机读：索引/数据页读取（缓冲池命中率决定实际磁盘读压力）。

随机写：脏页刷盘（后台异步），使用 direct IO。

顺序写：redo log 写入，通常同步刷盘（innodb_flush_log_at_trx_commit=1 或 =2）。

混合读写：正常业务负载。

#### 测试 1：随机读写混合（模拟一般 OLTP）
```shell
fio --name=mysql_randrw --directory=/data --filename=mysql_test --rw=randrw --rwmixread=70 --bs=16k --iodepth=64 --direct=1 --numjobs=8 --size=50G --runtime=120s --time_based --group_reporting --output=mysql_randrw.txt
```
参数说明

参数	含义
--rw=randrw	随机混合读写
--rwmixread=70	读占比 70%，写占比 30%
--bs=16k	InnoDB 页大小
--iodepth=64	高并发深度
--numjobs=8	8 个并发线程模拟多连接
预期输出示例

```text
READ: bw=156MiB/s (164MB/s), 156MiB/s-156MiB/s (164MB/s-164MB/s), io=18.3GiB (19.6GB), run=120001msec
WRITE: bw=66.8MiB/s (70.0MB/s), 66.8MiB/s-66.8MiB/s (70.0MB/s-70.0MB/s), io=7.84GiB (8.42GB), run=120001msec
```
总 IOPS ≈ (156+66.8) MiB/s ÷ 16 KiB ≈ (222.8 MiB/s) ÷ 16 KiB = 14259 IOPS。

混合读写时重点关注 写延迟 和 读延迟。

#### 测试 2：随机写（模拟后台刷脏页）
```shell
fio --name=mysql_randwrite --directory=/data --filename=mysql_randwrite --rw=randwrite --bs=16k --iodepth=64 --direct=1 --numjobs=4 --size=50G --runtime=120s --time_based --group_reporting --output=mysql_randwrite.txt
```
预期输出示例

```text
WRITE: bw=204MiB/s (214MB/s), 204MiB/s-204MiB/s (214MB/s-214MB/s), io=23.9GiB (25.7GB), run=120001msec
iops        : min=  250, max= 18000, avg=13056.00, stdev=1200.00
```
平均 IOPS 约为 13056，延迟通常在几毫秒内。

测试 3：顺序写（模拟 redo log）
```shell
fio --name=mysql_seq_write --directory=/data --filename=mysql_redo --rw=write --bs=1M --iodepth=32 --direct=1 --numjobs=1 --size=50G --runtime=120s --time_based --group_reporting --output=mysql_seq_write.txt
```
预期输出示例

```text
WRITE: bw=512MiB/s (537MB/s), 512MiB/s-512MiB/s (537MB/s-537MB/s), io=60.0GiB (64.4GB), run=120001msec
```
大块顺序写通常能跑满磁盘带宽，例如 NVMe SSD 可达到 3-5 GB/s。

#### 测试 4：同步顺序写（模拟 redo log 同步刷盘）
```shell
fio --name=mysql_sync_write --directory=/data --filename=mysql_redo_sync --rw=write --bs=8k --iodepth=1 --direct=1 --sync=1 --numjobs=1 --size=20G --runtime=120s --time_based --group_reporting --output=mysql_sync_write.txt
```
参数说明

--bs=8k：redo log 块大小（通常为 512B 或 4KB，此处取 8KB 便于测试）。

--sync=1：每次写入后调用 fsync，模拟 innodb_flush_log_at_trx_commit=1。

预期输出示例

```text
WRITE: bw=20.5MiB/s (21.5MB/s), 20.5MiB/s-20.5MiB/s (21.5MB/s-21.5MB/s), io=2.46GiB (2.64GB), run=120001msec
```
同步写性能受磁盘延迟和 RAID 控制器影响较大。

三、结果关键指标解读
fio 输出中需要关注的几个指标：

指标	含义	示例值
bw	带宽（MiB/s 或 MB/s）	256MiB/s
iops	每秒 IO 操作次数	13056
lat (usec)	平均延迟（微秒）	200.00
clat	完成延迟（从提交到完成）	关键值
slat	提交延迟（从生成到提交）	通常很小
lat	总延迟（slat+clat）	-
io	总数据量	30.0GiB
run	运行时间	120001msec
示例片段

```text
write: IOPS=15.0k, BW=234MiB/s (245MB/s)(28.1GiB/120001msec)
slat (usec): min=2, max=345, avg= 4.12, stdev= 2.34
clat (usec): min=12, max=10234, avg= 180.23, stdev= 150.12
lat (usec): min=15, max=10345, avg= 184.35, stdev= 152.45
```
平均完成延迟 180 µs，最大延迟 10.2 ms。

四、注意事项
测试路径：必须将 --directory 设置为目标磁盘挂载点，避免测试系统盘。

文件大小：--size 应大于磁盘缓存容量，建议至少 2~3 倍内存大小，避免缓存影响。

数据清理：测试结束后删除生成的测试文件，释放空间。

多次测试：建议重复 3 次取平均值，排除偶然波动。

监控：测试期间用 iostat -x 1 观察磁盘实际负载，确认是否达到设备极限。

安全：若数据库正在运行，测试可能干扰性能，建议在业务低峰期或从库进行。

一、关键参数说明
参数	说明
--name	测试任务名称，用于标识和输出分组。
--directory	测试文件存放目录，必须指向目标磁盘挂载点。
--filename	测试文件名。多个 job 时会自动追加编号（如 .0.0）。
--rw	读写模式：read（顺序读）、write（顺序写）、randread（随机读）、randwrite（随机写）、randrw（混合随机读写）。
--rwmixread	混合读写时读操作占比（如 70 表示 70% 读，30% 写）。
--bs	块大小（如 16k、1M）。影响 IOPS 和带宽。
--iodepth	异步 I/O 队列深度，表示每个线程允许的最大未完成 I/O 请求数。高深度可提升吞吐，但可能增加延迟。
--ioengine	I/O 引擎：libaio（异步，推荐）、psync（同步，用于 --sync=1）。
--direct	1 表示绕过页缓存（O_DIRECT），直接读写磁盘，测试真实性能。
--sync	1 表示每次写入后调用 fsync()，确保数据落盘，模拟数据库事务日志同步。
--numjobs	并发线程（进程）数。多个线程同时工作，模拟多客户端压力。
--size	每个 job 的测试文件大小（如 100G）。配合 --time_based 时，文件初始大小为此值，测试中会持续扩展。
--runtime	测试运行时长（如 120s）。与 --time_based 配合时，忽略 --size 限制，持续运行指定时长。
--time_based	启用后，测试在 --runtime 时长内持续运行，即使已写入超过 --size 的数据。
--group_reporting	汇总所有 job 的结果，便于查看整体性能。
--output	结果输出文件路径。

### 脚本 1：基础性能测试（顺序、随机、混合）
```shell
#!/bin/bash
# 通用磁盘性能测试脚本
# 用途：评估磁盘的顺序/随机读写吞吐、IOPS 及延迟

# 配置参数（可根据实际环境调整）
TEST_DIR="/data/fio_test"          # 目标测试目录（必须挂载在待测磁盘）
SIZE="20G"                        # 测试文件大小，建议大于内存 2~3 倍
RUNTIME="120s"                     # 测试持续时间
JOBS_SEQ=1                         # 顺序读写线程数（保持单线程）
JOBS_RAND=4                        # 随机读写线程数（模拟多队列）
JOBS_MIX=8                         # 混合读写线程数（模拟高并发）

# 创建测试目录
mkdir -p $TEST_DIR
cd $TEST_DIR

# 1. 顺序写（大块）—— 模拟 RDB 快照、备份
fio --name=seq_write \
    --directory=$TEST_DIR \
    --filename=base_seqwrite \
    --rw=write \
    --bs=1M \
    --iodepth=32 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=$JOBS_SEQ \
    --size=$SIZE \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=seq_write.txt

# 2. 顺序读（大块）—— 模拟全表扫描、大文件读取
fio --name=seq_read \
    --directory=$TEST_DIR \
    --filename=base_seqread \
    --rw=read \
    --bs=1M \
    --iodepth=32 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=$JOBS_SEQ \
    --size=$SIZE \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=seq_read.txt

# 3. 随机写（16K）—— 模拟脏页刷盘、日志写入
fio --name=randwrite \
    --directory=$TEST_DIR \
    --filename=base_randwrite \
    --rw=randwrite \
    --bs=16k \
    --iodepth=64 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=$JOBS_RAND \
    --size=$SIZE \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=randwrite.txt

# 4. 随机读（16K）—— 模拟索引查询、点查
fio --name=randread \
    --directory=$TEST_DIR \
    --filename=base_randread \
    --rw=randread \
    --bs=16k \
    --iodepth=64 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=$JOBS_RAND \
    --size=$SIZE \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=randread.txt

# 5. 混合读写（70%读，30%写）—— 模拟 OLTP 混合负载
fio --name=randrw \
    --directory=$TEST_DIR \
    --filename=base_randrw \
    --rw=randrw \
    --rwmixread=70 \
    --bs=16k \
    --iodepth=64 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=$JOBS_MIX \
    --size=$SIZE \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=randrw.txt

echo "基础测试完成，结果保存在 $TEST_DIR/*.txt"
```

```shell
#!/bin/bash
# Redis 磁盘性能测试脚本
# 用途：评估 Redis RDB 快照、AOF 日志写入及缓存未命中时的随机读性能

TEST_DIR="/data/fio_test"
RUNTIME="120s"
SIZE_RDB="20G"          # RDB 文件大小
SIZE_AOF_ASYNC="10G"     # AOF 异步写测试文件大小
SIZE_AOF_SYNC="4G"      # AOF 同步写测试文件大小（防止磁盘空间不足）
SIZE_RANDREAD="10G"      # 随机读测试文件大小

mkdir -p $TEST_DIR
cd $TEST_DIR

# 1. RDB 顺序写（大块，异步）—— 模拟 RDB 快照生成
fio --name=redis_rdb \
    --directory=$TEST_DIR \
    --filename=redis_rdb \
    --rw=write \
    --bs=1M \
    --iodepth=32 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=1 \
    --size=$SIZE_RDB \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=redis_rdb.txt

# 2. AOF 异步写（小块，异步）—— 模拟 appendfsync everysec
fio --name=redis_aof_async \
    --directory=$TEST_DIR \
    --filename=redis_aof_async \
    --rw=write \
    --bs=8k \
    --iodepth=64 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=1 \
    --size=$SIZE_AOF_ASYNC \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=redis_aof_async.txt

# 3. AOF 同步写（小块，同步）—— 模拟 appendfsync always
fio --name=redis_aof_sync \
    --directory=$TEST_DIR \
    --filename=redis_aof_sync \
    --rw=write \
    --bs=8k \
    --iodepth=1 \
    --ioengine=psync \
    --direct=1 \
    --sync=1 \
    --numjobs=1 \
    --size=$SIZE_AOF_SYNC \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=redis_aof_sync.txt

# 4. 随机读（16K）—— 模拟缓存未命中时的数据读取
fio --name=redis_randread \
    --directory=$TEST_DIR \
    --filename=redis_randread \
    --rw=randread \
    --bs=16k \
    --iodepth=64 \
    --ioengine=libaio \
    --direct=1 \
    --numjobs=4 \
    --size=$SIZE_RANDREAD \
    --runtime=$RUNTIME \
    --time_based \
    --group_reporting \
    --output=redis_randread.txt

echo "Redis 测试完成，结果保存在 $TEST_DIR/*.txt"
```
