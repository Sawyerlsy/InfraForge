要查看 NFS 挂载参数的默认值，通常有三种方法：查阅官方手册、检查系统配置或进行简单的命令行测试。

`timeo` 的默认值与 NFS 协议版本和传输协议有关。在大多数现代 Linux 发行版（如 CentOS 7/8、Ubuntu 18.04+）的默认配置下，NFSv3 或 v4 挂载点通常使用 TCP 协议，因此 `timeo` 的默认值是 **600**，即 60 秒。如果系统因历史原因使用 UDP 协议，则默认值为 **7**，即 0.7 秒。

---

### 如何查看默认值

以下方法可以帮你确认当前系统的默认值：

#### 1. 查看生效的挂载参数（最直接）
在没有显式指定 `timeo` 的情况下，直接在已挂载的 NFS 目录上查看其生效参数，可以确认系统的默认值。
```bash
# 方法一：通过/proc/mounts查看所有挂载点的生效参数（最准确）
cat /proc/mounts | grep nfs
# 或针对特定挂载点
cat /proc/mounts | grep "/your_nfs_mount_point"

# 方法二：使用nfsstat -m查看详细的NFS挂载参数
nfsstat -m
```
以上命令输出中的 `timeo` 值，就是当前挂载正在使用的数值。

#### 2. 查阅系统手册页（官方定义）
```bash
man nfs
```
在手册页中查找 `timeo` 选项，可以看到官方对于默认值的定义。

#### 3. 检查系统配置文件（非实时）
虽然系统配置文件（如 `/etc/nfsmount.conf`）可以设定全局默认值，但它并非在所有发行版中都默认存在。最可靠的还是使用方法一查看系统当前生效的配置。

#### 4. 通过简单测试验证
你也可以在不挂载的情况下，测试 RPC 的超时行为来推断默认值，但这更多是用于诊断问题而非直接查看配置。

---

总的来说，你的 NFS 环境很可能使用的是 TCP 协议和默认的 `timeo=600`（60秒）配置，这意味着它能较好地容忍单次 RPC 耗时较长的场景。如果想调整它，你可以在挂载时用 `-o` 选项显式指定，例如 `-o timeo=300`（30秒）。
